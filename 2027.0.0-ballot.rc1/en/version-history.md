## Versioning

 This page includes translations from the original source language in which the guide was authored. Information on these translations and instructions on how to provide feedback on the translations can be found [here](translationinfo.html). 

The module Pathology Report follows the versioning of the MII core data set: a version is bound to the year of its publication (e.g. `2027.0.0`). The dependencies on the other MII modules are set to the annual version matching the respective release.

| :--- | :--- |

The content-related changes of the individual versions are documented in the [changelog](changes.md).

Earlier editions of the implementation guide are available via the [Simplifier project](https://simplifier.net/medizininformatikinitiative-modulpathologie) as well as via the [releases in the GitHub repository](https://github.com/medizininformatik-initiative/kerndatensatzmodul-PathologieBefund/releases).
