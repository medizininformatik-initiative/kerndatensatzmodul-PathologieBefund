## References

 This page includes translations from the original source language in which the guide was authored. Information on these translations and instructions on how to provide feedback on the translations can be found [here](translationinfo.html). 

The information model of the module Pathology Report contains references to the following projects:

* [IHE Anatomic Pathology Structured Report (APSR)](https://wiki.ihe.net/index.php/Anatomic_Pathology_Structured_Report)
* [International Patient Summary (IPS)](http://hl7.org/fhir/uv/ips/history.html)
* [ISiK specification](https://simplifier.net/packages/de.gematik.isik-basismodul/4.0.1)

Complete, exemplary implementations of this module's profiles as separate implementation guides:

* [Breast Cancer Spec IG](https://bih-cei.github.io/BreastCancerSpec/) — breast-conserving therapy and breast resection specimen, including localization by means of BodyStructure
