Diese Seite verlinkt die herunterladbaren Artefakte dieses Implementation Guide.

### Paketdatei

Die folgende Paketdatei ist ein NPM-Package, wie es von vielen FHIR-Werkzeugen verwendet wird. Es enthält alle ValueSets, Profile, Extensions, Seiten und URLs dieser Version des Implementation Guide. Diese Datei **SOLLTE** die erste Wahl sein, wenn Implementierungsartefakte erzeugt werden, da sie sämtliche Regeln enthält, die die Profile gültig machen.

- [Package (komprimierter Ordner)](../package.tgz){::download="true"}

Einbindung als Abhängigkeit in `sushi-config.yaml`:

```yaml
dependencies:
  de.medizininformatikinitiative.kerndatensatz.patho: 2027.0.0-ballot.rc
```
