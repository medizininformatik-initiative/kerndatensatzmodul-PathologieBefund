The information model of the module Pathology Report contains references to the following projects:

* [IHE Anatomic Pathology Structured Report (APSR)](https://wiki.ihe.net/index.php/Anatomic_Pathology_Structured_Report)

* [International Patient Summary (IPS)](http://hl7.org/fhir/uv/ips/history.html)

The individual references to the APSR ART-DECOR project can be found at the corresponding data elements of the extension module Pathology Report.

In addition, the module builds on version R4 of the [HL7 FHIR core specification](http://hl7.org/fhir/r4), in particular on the corresponding resources [DiagnosticReport](http://hl7.org/fhir/r4/diagnosticreport.html), [ServiceRequest](http://hl7.org/fhir/r4/servicerequest.html), [Specimen](http://hl7.org/fhir/r4/specimen.html) and [Observation](http://hl7.org/fhir/r4/observation.html). In terms of content, the requirements of [DIN EN ISO/IEC 17020:2012](https://www.din.de/de/mitwirken/normenausschuesse/nqsz/veroeffentlichungen/wdc-beuth:din21:146320816) are taken into account.

This specification was designed on the basis of the description of the MII core data set in the [version of 10 March 2017](https://www.medizininformatik-initiative.de/sites/default/files/inline-files/MII_04_Kerndatensatz_1-0.pdf) as well as the data set description in [Art-Decor](https://art-decor.org/art-decor/decor-project--mide\-).

In addition, due to the proximity to the care structures in the hospital, there are references from and to the [ISiK specification](https://simplifier.net/packages/de.gematik.isik-basismodul/4.0.1).
