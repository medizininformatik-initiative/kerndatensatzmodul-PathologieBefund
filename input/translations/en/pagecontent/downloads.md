This page links the downloadable artifacts of this implementation guide.

### Package file

The following package file is an NPM package as it is used by many FHIR tools. It contains all ValueSets, profiles, extensions, pages and URLs of this version of the implementation guide. This file **SHOULD** be the first choice when implementation artifacts are generated, because it contains all the rules that make the profiles valid.

- [Package (compressed folder)](../package.tgz){::download="true"}

Inclusion as a dependency in `sushi-config.yaml`:

```yaml
dependencies:
  de.medizininformatikinitiative.kerndatensatz.patho: 2027.0.0-ballot.rc1
```
