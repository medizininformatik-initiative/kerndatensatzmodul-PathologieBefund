## Hinweise zur Übersetzung

### Übersetzungsinformationen

Dieser Implementation Guide ist in **Deutsch** verfasst — das ist die Quellsprache — und wird zusätzlich in **Englisch** unter `/en/` gerendert. Die Sprache lässt sich über die Auswahl in der Navigationsleiste umschalten.

Die englische Fassung wird in diesem Repository von Hand gepflegt, sie ist keine maschinelle Übersetzung:

| | |
| :--- | :--- |
| Narrative Seiten | `input/translations/en/pagecontent/`— je Quellseite eine Datei mit gleichem Dateinamen |
| Profil-Prosa (Intro-Notes) | `input/translations/en/intro-notes/` |
| Titel, Beschreibungen und Element-Definitionen der Ressourcen | `input/translations/en/*.po`— je Ressource ein Übersetzungskatalog |

Eine Seite ohne englische Entsprechung wird unter `/en/` auf Deutsch gerendert, mit einem entsprechenden Hinweis am Seitenanfang.

#### Teilweise übersetzte Inhalte

Einige Inhalte sind derzeit nur auf Deutsch verfügbar:

* **UML- und ART-DECOR-Abbildungen** — die Grafiken enthalten deutsche Beschriftungen
* **Logisches Modell** — die Elementnamen des logischen Datenmodells bleiben deutsch, nur die Beschreibungen sind übersetzt
* **Profile** — Profilseiten können gemischt englische und deutsche Inhalte enthalten, da FHIR-Kernelemente englisch sind, während Extensions und Datentypen aus den Deutschen Basisprofilen deutsche Beschreibungen und Terminologie mitbringen

#### Rückmeldungen zur Übersetzung

Anmerkungen zu einer Übersetzung bitte als Issue im [GitHub-Repository](https://github.com/medizininformatik-initiative/kerndatensatzmodul-PathologieBefund) oder über die HL7-FHIR-Zulip, Stream `german/mi-initiative` ([https://chat.fhir.org](https://chat.fhir.org)), jeweils unter Angabe der Seite und der Formulierung.
