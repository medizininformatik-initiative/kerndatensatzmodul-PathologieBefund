## Versionierung

Das Modul Pathologie-Befund folgt der Versionierung des MII-Kerndatensatzes: Eine Version ist an das Jahr ihrer Veröffentlichung gebunden (z. B. `2027.0.0`). Die Abhängigkeiten zu den anderen MII-Modulen werden jeweils auf die zum Release passende Jahresversion gesetzt.

| | |
| :--- | :--- |
| Aktuelle Version | 2027.0.0-ballot.rc |
| Package-ID | de.medizininformatikinitiative.kerndatensatz.patho |
| Canonical | https://www.medizininformatik-initiative.de/fhir/ext/modul-patho |
| FHIR-Version | R4 (4.0.1) |

Die inhaltlichen Änderungen der einzelnen Versionen sind im [Changelog](changes.md) dokumentiert.

Ältere Fassungen des Implementation Guide sind über das [Simplifier-Projekt](https://simplifier.net/medizininformatikinitiative-modulpathologie) sowie über die [Releases im GitHub-Repository](https://github.com/medizininformatik-initiative/kerndatensatzmodul-PathologieBefund/releases) erreichbar.
