Ressourcenprofil: MII PR Patho Bundle

Offizielle URL: https://www.medizininformatik-initiative.de/fhir/ext/modul-patho/StructureDefinition/mii-pr-patho-bundle Version: 2027.0.0-ballot.rc
Active Stand: 2026-09-01 Maschinenlesbarer Name: MII_PR_Patho_Bundle

Dieses Profil MII PR Patho Bundle erbt von Profile - ISiK - BerichtSubsysteme aus der Spezifikation ISiK - Stufe 5. Es dient der Aggregation aller Ressourcen, die Bestandteil des Dokumentes sind. Dabei sollte die erste Ressource im Bundle (Bundle.entry.resource) stets eine Composition sein.

Das Profil verwendet Bundle.type = “document” und einen persistenten, eindeutigen Bundle.identifier. Dieser sollte dem Composition.identifier entsprechen, beispielsweise einer Eingangsnummer inklusive Versionsnummer. Weitere Slices von Bundle.entry sind ServiceRequest, Specimen, DiagnosticReport, Observation und Patient. Wobei die Slices ServiceRequest und Patient optional sind. Das Bundle enthält eine Signatur.

Usages:

  • This Profile is not used by any profiles in this Specification

You can also check for usages in the FHIR IG Statistics
